## Commands

```bash
pnpm dev              # Local dev server (http://localhost:3000)
pnpm build            # Production build
pnpm extract-colors   # Extract colors + EXIF from photos, generate data/photos.json
```

## Architecture

A personal photography portfolio site built with Next.js 16 (App Router) + Tailwind CSS + Leaflet + Recharts.

### Pages (4 routes)

| Route | Page | Purpose |
|-------|------|---------|
| `/` | `app/page.tsx` | Hero with radial gradient background, snap-scroll to gallery preview |
| `/gallery` | `app/gallery/page.tsx` | Color-filtered photo grid with modal |
| `/map` | `app/map/page.tsx` | China map (Gaode tiles via Leaflet) with location markers |
| `/analytics` | `app/analytics/page.tsx` | Charts: time distribution, color distribution, location stats, camera stats |
| `/photo/[id]` | `app/photo/[id]/` | Server component + client component split for static generation |

### Data flow

- `data/photos.json` — Canonical photo metadata (title, URL, location coords, colors, EXIF)
- `lib/photos.ts` — Reads `photos.json`, provides `getAllPhotos()`, `getPhotoById()`, filters
- `lib/colors.ts` — Color utilities: hex parsing, HSL, 12-category classification (red/blue/green/etc.)
- `lib/analytics.ts` — Aggregation functions for charts (by month, season, color, location, camera)
- `lib/store.ts` — `useEditedPhotos()` hook: loads photos + merges localStorage edits after client mount to avoid hydration mismatch

### Photo storage

- `public/photos/` — Original photos (deployed to production, served as static assets)
- `public/thumbnails/` — 400px-wide thumbnails generated by extraction script
- `source-photos/` — Local backup of original photos (gitignored, not deployed)

### Key components

- `MapView.tsx` — Leaflet map with Gaode tiles (works in China without VPN), grouped location markers with popup thumbnails
- `PhotoModal.tsx` — Photo detail modal with color palette, EXIF info, edit button
- `EditPanel.tsx` — Inline editor for photo location/title, saves to localStorage
- `AddPhotoModal.tsx` — Add custom photos via URL, auto-extracts dominant color from image pixel, saves to localStorage
- `Charts.tsx` — Five Recharts components: MonthlyChart, SeasonChart, ColorChart, LocationChart, CameraChart
- `ColorBar.tsx` — 12-color filter bar for gallery page

### Color extraction script

`scripts/extract-colors.ts` processes photos from `source-photos/` using sharp + exifr:
1. Resizes to 400px thumbnail, writes to `public/thumbnails/`
2. Samples dominant color from thumbnail pixels
3. Reads EXIF (camera, lens, ISO, aperture, shutter, GPS)
4. Writes `data/photos.json`

### Important constraints

- **No heavy CSS blur or infinite animations** — Caused GPU memory issues on macOS. Use `radial-gradient` for backgrounds, `animate-fadeIn` (runs once, stops with `forwards`)
- **Photos must stay under ~100MB total** for deployment limits. Use `sharp` to compress large files (`resize({ width: 1920 }).jpeg({ quality: 82 })`)
- **Shell working directory** — `pnpm` commands when run from `/Users/cdm/vscode` will fail. Always run from `/Users/cdm/vscode/personal-photograph-show`
- **Cloudflare deployment** — Uses `@cloudflare/next-on-pages`. Build command: `npx @cloudflare/next-on-pages@1`, output dir: `.vercel/output/static`
